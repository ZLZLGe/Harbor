# Investor Materials

## What This Skill Does

This skill helps assemble fundraising materials from a current company fact set and keeps the numbers aligned across all investor-facing outputs.

## When To Use

Use this skill when you need to:

- prepare an investor memo
- prepare a one-pager
- prepare a fundraising financial model
- prepare a use-of-funds table
- update multiple investor-facing materials without letting company facts drift

## Core Workflow

1. Build a current fact sheet before drafting any material.
2. Mark any stale or conflicting values and replace them with the approved current values.
3. Draft each deliverable from the same fact sheet.
4. Recheck raise terms, pricing, customer metrics, market metrics, and milestone timing across every file.
5. Confirm that all arithmetic in the model and use-of-funds table closes cleanly.

## Output Expectations

- Investor memo with clear company, market, traction, raise, and milestone sections.
- One-pager with a short current summary of the company and round.
- Financial model that rolls forward cleanly from the approved assumptions.
- Use-of-funds table that matches the target raise amount.

## Final Checks

- Current values are used everywhere.
- Older draft values do not appear in the final materials.
- Money amounts and operating metrics match across files.
- Market claims match the approved source inputs.
