GitHub Copilot code review will start consuming GitHub Actions minutes on June 1, 2026

2026-04-27T15:59:24Z

GitHub is warning customers ahead of a billing change: Copilot code review will consume GitHub Actions minutes starting June 1, 2026.

GitHub frames this as a billing and workflow update for teams using Copilot code review on pull requests, with notice ahead of the June 1, 2026 change.

Because the code review agent runs on GitHub Actions, the change affects cost planning, repository policy choices, and the way engineering teams budget automated review activity.
