Upcoming deprecation of GPT-5.2 and GPT-5.2-Codex

2026-05-01T21:30:12Z

We will deprecate GPT-5.2 and GPT-5.2-Codex across GitHub Copilot experiences, with dates that require teams to update workflows and model policies.

GitHub says GPT-5.2 and GPT-5.2-Codex will be deprecated across GitHub Copilot experiences, and it names June 1, 2026 as the key cutover date for most usage paths.

The notice tells administrators and integration owners to update workflows and confirm alternative model availability before the deadline, which makes it an actionable deprecation for developer tooling teams.
