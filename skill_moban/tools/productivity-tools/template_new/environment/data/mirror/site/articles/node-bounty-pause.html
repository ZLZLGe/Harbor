Security Bug Bounty Program Paused Due to Loss of Funding

2026-04-02T12:00:00Z

The Node.js project paused its security bug bounty program after the supporting funding source was discontinued.

Node.js says its security bug bounty program is being paused because the external funding source behind the payouts was discontinued.

This changes part of the project security process and matters to teams that monitor disclosure and response channels, but it does not describe an active exploit, so medium priority is appropriate.
