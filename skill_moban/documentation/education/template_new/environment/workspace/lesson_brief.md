# New Analyst Workshop Brief

## Audience

This lesson is for new data analysts joining an internal learning analytics team.

## Teaching goal

Help learners practice how to turn raw event logs and quiz attempts into a short, trustworthy analysis notebook.

## Required coverage

- Explain what the workshop is trying to measure.
- Show how to inspect the event data before jumping into conclusions.
- Build a simple session funnel from learner events.
- Compare quiz outcomes without confusing learner-level and attempt-level metrics.
- Call out at least two metric definition traps from `metric_definitions.yaml`.
- End with at least one short practice block for the learner.

## Constraints

- Treat the provided metric definitions as the source of truth.
- Cite the visible input files when you explain a metric, result, or caveat.
- Do not claim causal impact from this single workshop snapshot.
- Keep the notebook beginner-friendly: short sections, clear labels, and explicit takeaways.
