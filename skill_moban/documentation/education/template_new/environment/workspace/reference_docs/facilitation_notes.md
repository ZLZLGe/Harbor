# Facilitation Notes

## Common teaching traps

1. Do not compute completion rate from raw event rows. Use unique learners.
2. Do not compute quiz pass rate from attempts if the definition says learner-level pass status.
3. Do not describe retry behavior as failure by default. Some learners retry after a first passing score to improve.
4. When you cite a metric definition, name the source file directly so another instructor can trace it.
