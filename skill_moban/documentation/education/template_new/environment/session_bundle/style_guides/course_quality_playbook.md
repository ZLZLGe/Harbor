# Course Quality Playbook Excerpt

Course releases should be reviewed as learner-facing systems, not as isolated files.

For each release, compare:

1. Course and lesson metadata in the LMS.
2. The current learning objective and prerequisite chain.
3. Video captions, transcripts, and other accessibility artifacts.
4. Assessment prompts, quiz rubrics, and answer explanations.
5. Reviewer comments and any CI warnings that were skipped or manually waived.

Use a standalone skill when a future agent needs a multi-step process with evidence gathering, decision points, and examples. Use a short repository instruction only when the learning is a small rule that applies automatically without a special workflow.

Bad capture: "Remember to check BIO-201 captions next time."

Better capture: "Before publishing an educational module, cross-check LMS metadata, learner-facing media, accessibility artifacts, and assessment rubrics against the current learning objectives and prerequisite contract."
