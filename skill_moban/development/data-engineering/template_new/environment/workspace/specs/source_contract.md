# Source Feed Contract

本任务使用冻结的 marketplace 原始 feed，覆盖订单 CDC、履约事件与退款流水三类来源。

## 订单 CDC

- 业务键为 `(order_id, line_id)`。
- 同一业务键可能出现多次重放、补发或状态更新；最终快照必须满足 replay-safe latest-version 语义。
- `ordered_at`、`updated_at`、`ingested_at` 可能带时区偏移，也可能是 UTC 记录。
- 金额字段处于迁移期，旧版与新版编码在同一冻结批次中可能共存；聚合前需要统一到美元两位小数口径。

## 履约事件

- 同一 `(order_id, line_id)` 下可能有多条履约记录。
- 发货时效以首个有效发货事件为准。
- 与订单时间做比较前，需要先统一到同一时间基准。

## 退款

- 同一订单行可能有多笔退款。
- 退款行数与退款金额都要按真实流水汇总，不能只看单条记录。

## 稳定性要求

- 结果不能依赖输入文件顺序。
- 结果不能依赖一次性手工整理某几条异常数据。
- 输出必须可在替代 fixture 下复用同样规则。
