# Silicone Process Sheet

The mold insert scan was exported in centimeters.

| Parameter | Value | Units |
| --- | --- | --- |
| Transfer factor | 1.00 | mL per cm^3 |
| Reserve percent | 8 | % |
| Fixed loss | 185 | mL |

Interpretation:
- `Transfer factor` converts the measured insert volume into net silicone fill volume.
- `Reserve percent` is applied to the net fill volume as a decimal percentage.
- `Fixed loss` covers cup wet-out and short runner losses.
