# INC-4821 Checkout Outage

- Opened: 2026-02-14T09:26:40Z
- Severity: SEV-1
- Summary: Elevated latency and 5xx responses on checkout-api caused checkout failures.
- Customer impact: 23% of checkout attempts failed between 09:16 UTC and 09:39 UTC. Cart view and login were unaffected.
- Mitigation: Disable `INVOICE_PREFETCH_MODE` for checkout-api.
- Current status: Recovered after mitigation; follow-up needed on rollout validation and query performance.
- Linked change: `CHG-771`
