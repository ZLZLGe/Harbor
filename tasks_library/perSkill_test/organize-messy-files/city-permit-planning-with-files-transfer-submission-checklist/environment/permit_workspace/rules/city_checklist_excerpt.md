# Harbor City Permit Counter Excerpt

For a commercial exterior alteration package, intake staff must confirm the following before the submittal can be accepted:

1. A signed permit application is required.
2. If the applicant is not the property owner, an owner authorization letter is required.
3. The site plan must show the parcel identifier and accessibility ramp details.
4. If added or replaced impervious area exceeds 800 square feet, a stormwater worksheet is required.
5. If the project fronts a service alley or public right-of-way, a neighbor notification affidavit is required.
6. The requested electrical service must match between the permit application and the electrical drawings.
7. The declared project valuation must be supported by attached contractor and traffic-control quotes.
8. Conflicting parcel identifiers or conflicting utility-service figures are intake blockers.
