质控实验员把本轮板式检测批次整理在 `/app/assay_batches.json` 中。每个条目都包含：

- `id`：批次编号
- `domain`：PDDL 域文件路径
- `problem`：PDDL 问题文件路径
- `plan_output`：该批次对应的输出计划文件路径
- `plate`：本批次使用的反应板
- `incubator`：孵育设备
- `washer`：清洗设备
- `reader`：读板设备
- `well_order`：需要按顺序完成混配、清洗和读板的孔位列表

你需要读取 `assay_batches.json` 中列出的全部实例，并为每个批次生成一份合法的顺序实验计划，逐个写入各自的 `plan_output` 路径。

要求：

- 每个输出文件都必须存在，不能遗漏任何批次。
- 计划必须符合对应 PDDL 域与问题文件中的动作定义和对象命名。
- 每个孔位都要先完成取样和加试剂，之后才能进入混配序列。
- 只有整板混配完成后才能孵育；只有孵育完成后才能按给定孔位顺序清洗；只有整板清洗完成后才能上机读板。
- 计划文件中每行只能有一个动作。
- 如有需要，请自行创建输出目录。

例如，`assay_plans/batch_red_plan.txt` 必须是其中一个生成出来的计划文件。
