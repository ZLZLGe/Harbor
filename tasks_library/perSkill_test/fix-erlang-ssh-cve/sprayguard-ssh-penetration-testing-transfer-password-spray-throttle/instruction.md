`/app/workspace` 里是一套 Python 实现的 SSH bastion 认证服务。

当前失败限速是按连接记录的，攻击者只要不停断开并重新建立 SSH 连接，就能绕过失败次数限制，继续做口令喷洒。你需要先确认是哪一类认证尝试会因为重连而把计数清空，再修复失败计数和封禁逻辑。

修复后需要同时满足：

- 同一来源在多个连接之间重复失败时，不能通过重连绕过限速
- 被限速后，在冷却窗口内即使换新连接也不能继续尝试
- 冷却时间过去后，合法用户仍然可以正常登录

把主要修改放在 `/app/workspace/bastion/auth/failure_tracker.py`，只修改提供的代码并让测试通过即可。
