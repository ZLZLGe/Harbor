当前工作目录下有一个本地 Python 仓库 `/app/archivekit_repo`，它实现了一个简化的归档文件读取器，并带有一组现有单元测试。

你的任务是阅读仓库结构、核心模块和 `tests/`，找出最值得后续做鲁棒性测试的目标，并把分析写到 `/app/archive_fuzz_targets.md`。

输出文件必须包含这四部分：

1. `Important Files`
   列出你认为最关键的源码文件，并说明它们为什么值得重点关注。
2. `Important Functions`
   列出关键函数或方法，说明输入面、复杂性、已有覆盖情况和潜在风险。
3. `Existing Tests And Gaps`
   总结现有测试已经覆盖了什么，再明确指出仍然缺失的边界条件、异常路径或输入类型。
4. `Final Shortlist`
   最终只保留 3 个最值得优先做后续测试的目标；每个目标都要写清楚：
   - 为什么优先级最高
   - 目前测试缺了什么
   - 适合作为后续测试输入的 seed 思路

额外要求：

- 不要修改 `/app/archivekit_repo` 里的源码或测试。
- 分析必须结合现有测试，而不是只看源码。
- 最终 shortlist 需要明确到具体函数或方法。
