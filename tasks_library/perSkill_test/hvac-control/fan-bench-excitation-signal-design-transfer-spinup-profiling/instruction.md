你在给一套离心风机台架做开环升速摸底。目标不是闭环控制，而是设计一次信息量足够、又不会把电机推到饱和区的电压阶跃实验，留下可用于后续辨识的启动轨迹。

可用输入资产：
- `/root/fan_spinup_simulator.py`：风机升速模拟器。
- `/root/fan_bench_profile.json`：可见的台架约束、采样周期和安全工作区说明。

请在 `/root/spinup_trace.csv` 写出一次连续实验的轨迹，CSV 头必须正好是：

```csv
time_s,drive_voltage_v,measured_rpm
```

输出契约：
- 只需要提交这一个 CSV 文件，不要额外提交参数估计报告。
- 轨迹必须来自同一次连续开环实验，时间从 `0` 开始，且严格递增。
- 实验必须先保持一段基线，再切换到一次固定正向电压阶跃，并一直保持到实验结束；不允许多次切换、电压扫描或脉冲串。
- 基线段电压必须为 `0.0 V`，持续时间至少 `1.0` 秒。
- 阶跃电压必须落在 `5.5` 到 `8.5` 伏之间，并且切换后保持恒定。
- 阶跃后的保持段持续时间至少 `8.0` 秒。
- 实际采样间隔必须与 `/root/fan_bench_profile.json` 里的 `sample_period_s` 一致。
- 为了证明这次激励足够有信息量，末尾 `20` 个样本的平均转速相对阶跃前基线平均转速的提升必须至少达到 `1200 RPM`。
- 为了证明没有把系统推到明显饱和区，整个轨迹中的最大转速必须严格低于 `/root/fan_bench_profile.json` 里的 `soft_rpm_ceiling_rpm`。
- 评测会直接根据你提交的轨迹复算一阶升速模型参数，因此这条轨迹必须足够清晰，使得从该轨迹反算得到的电机增益误差不超过 `12%`、时间常数误差不超过 `15%`。

约束：
- 不要修改 `/root/fan_spinup_simulator.py` 或 `/root/fan_bench_profile.json`。
- 输出必须是合法 CSV，并包含至少 `180` 行数据（不含表头）。
- `measured_rpm` 需要原样记录模拟器给出的观测值，不要额外平滑到只剩下理想曲线。
