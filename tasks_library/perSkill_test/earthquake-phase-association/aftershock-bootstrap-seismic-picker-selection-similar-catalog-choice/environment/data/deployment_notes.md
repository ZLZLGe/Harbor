Temporary deployment summary
============================

- A six-station broadband array was installed 36 hours after the mainshock to bootstrap a local aftershock catalog.
- The team needs a practical automatic catalog from continuous data before doing any detailed relocation work.
- Only two early hand-picked reference events exist, and they do not cover the full range of later aftershock waveforms or source areas.
- Several stations sit near pumps and access roads, so simple amplitude triggers produce many false alarms during this sequence.
- The reviewed windows below are only a spot check. Once you decide which candidate family is most appropriate, keep all valid events from that candidate across the full interval.
