This box is mounted near a coastal town and must raise a first-stage local trigger before the uplink finishes sending data to the regional center.

Only one CPU core is reserved for triggering because the other cores handle telemetry, buffering, and a watchdog process. There is no GPU or other accelerator on the device.

The link is intermittent, so the trigger must run continuously on the box without downloading large models or relying on outside services.

This site is newly instrumented. There is no historical event library that could be used as a waveform template bank.

The operator accepts a small number of extra internal alerts each week if that is what it takes to avoid missing clear nearby earthquakes. The goal is a fast practical trigger for obvious impulsive arrivals, not the most complete possible microseismic catalog.
