# Project conventions for proof-session memory notes

1. Each reusable note should cite concrete evidence using repository-relative file paths.
2. Successful proof notes should mention the goal shape, the tactic sequence that unlocked it,
   and any helper facts or tactics that made the final inequality trivial.
3. Failed-attempt notes should record both the failure signal and the next better direction,
   so future sessions can avoid repeating the same dead end.
4. Advice for later sessions should be phrased around theorem families, not one-off line edits.
