## Task Description

`/app/workspace/scheduler_source.py` models batch jobs in Python.

Create `/app/workspace/transfer1.scala` that preserves the same object model intent in idiomatic Scala 2.13.

Requirements:

1. Represent a base job contract with abstract behavior.
2. Represent concrete job variants with overridden execution text.
3. Preserve builder/factory-style creation as a companion-object style API.
4. Preserve a batch-running abstraction equivalent to `run_batch`.
5. Keep the code readable and maintainable, using Scala naming and structure conventions.
