## Task Description

`/app/workspace/plugins_source.py` describes a plugin registry and execution flow.

Create `/app/workspace/transfer3.scala` that captures the design with idiomatic Scala 2.13 object-oriented modeling.

Requirements:

1. Model plugin behavior as a Scala trait-like contract.
2. Model result payload as immutable data.
3. Model registry lifecycle with class-based state.
4. Preserve construction helpers analogous to static/class-level constructors.
5. Keep naming and organization maintainable for production code review.
