## 任务说明

`/app/workspace/intake_packet/` 下提供了两份输入文件：

- `patient_registration.json`：住院登记信息。
- 同目录里唯一的那份两页空白入院表文档。

请根据 JSON 中的内容完成这份表单，并将最终结果写入该任务要求的最终输出文件。

输出必须满足以下要求：

- 结果必须是一个可打开的两页表单文档，并且必须使用该任务要求的最终输出路径与文件名。
- 保留原始表单的两页结构，不要拆分、删页或改成其他格式。
- 保留原有的可填写字段集合，不要删除字段、改名、增加新字段，也不要把字段全部烘焙成不可读取的纯页面内容。
- 需要正确填写文本输入项、下拉选项和复选框。
- JSON 中的布尔值必须正确映射为勾选状态。
- 表单中已有默认值的字段，必须按 JSON 覆盖为正确值。
- 下拉字段只能选择表单中已有选项，不要自行添加新选项。
- 不要输出额外的最终答案文件。
