给定无人机屋顶巡检视频 `/root/rooftop_inspection.y4m` 和说明文件 `/root/heatmap_spec.json`，请输出 `/root/rooftop_activity_heatmap.npy`，表示整段片段中的累计动态活动热力图。

当前环境提供了可用于估计动态前景掩码的能力。你可以利用这些能力提取每个采样帧中的动态前景掩码，再把这些掩码累计成热力图。

输出要求如下：

1. 按 `/root/heatmap_spec.json` 中的 `sample_fps` 对整段视频做固定采样，覆盖完整视频时长。
2. 对每个采样帧，估计相对屋顶背景发生独立运动的前景区域；热力图中的每个像素值表示该像素在多少个采样帧里被判为动态前景。
3. 最终结果必须是一个二维 `NumPy` 数组，保存到 `/root/rooftop_activity_heatmap.npy`。
4. 数组形状必须与 `/root/heatmap_spec.json` 里的 `expected_shape` 一致，元素类型必须是浮点数，且所有值都在 `[0, 1]` 范围内。
5. 必须对累计结果做全局归一化：用整张累计图中的最大值去除所有像素；如果整段视频都没有检测到动态前景，则输出全零数组。
6. 热力图中数值越大，表示该像素在整段巡检中越频繁地被移动人员或设备占据。

评测说明：

1. 评测会先检查文件存在、二维形状、浮点类型、有限值，以及数值是否落在 `[0, 1]` 内。
2. 对这段素材，评测要求输出已经按全局最大值完成归一化，因此热力图峰值必须 `>= 0.95`。
3. 这段屋顶巡检素材中确实存在动态前景；正确结果不应是全零热力图。
4. 评测会使用参考采样掩码累计出基准热力图，并对预测热力图与基准热力图都做 `5x5` 方框模糊后计算指标。要求满足：
   - 模糊后 MAE `<= 0.12`
   - 模糊后 cosine similarity `>= 0.82`
   - 将模糊后热力图中 `>= 0.35` 的区域视为热点区域后，precision `>= 0.37`
   - 将模糊后热力图中 `>= 0.35` 的区域视为热点区域后，recall `>= 0.55`
   - 总热力质量比 `pred.sum() / ref.sum()` 必须落在 `[0.55, 1.8]`
   - 热力图加权质心与基准热力图加权质心的欧氏距离 `<= 18.0` 像素
