给定一段传送带生产线监控视频 `/root/input.mp4`，请按 `fps = 5` 做固定速率采样，并输出一个 JSON 文件 `/root/pred_line_state_spans.json`。

这个 JSON 必须把连续采样编号区间映射到产线状态标签：

- 键必须严格写成 `"start->end"`。
- `start` 和 `end` 都是采样编号，不是原始视频帧号。
- 区间语义是左闭右开，表示覆盖 `start, start + 1, ..., end - 1` 这些采样帧。
- 所有采样编号都必须被覆盖且只能被覆盖一次，不能有重叠，也不能漏掉。
- 值必须是只含 1 个字符串的数组，合法标签只有：
  - `Empty`
  - `Flowing`
  - `Backlog`

示例格式：

```json
{
  "0->3": ["Empty"],
  "3->8": ["Flowing"]
}
```

请特别注意：状态切换必须对齐到采样编号边界，不要把原始帧号直接写进结果。
