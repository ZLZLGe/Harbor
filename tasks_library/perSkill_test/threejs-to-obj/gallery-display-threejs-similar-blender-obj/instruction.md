你需要把一个展台装配体场景模块导出成 Blender 可导入的单个 OBJ 文件。

输入模块位于 `/root/data/display_scene.js`，它导出 `createDisplayAssembly()`，返回装配体根节点。场景里包含多层嵌套分组、非均匀缩放、镜像缩放，以及 `InstancedMesh` 形式的紧固件阵列；另外还包含不可见的校准部件，这些不可见内容不应进入结果。

请编写并运行你自己的脚本，生成 `/root/output/display.obj`，并满足以下要求：

- 只导出最终可见装配体，任何不可见节点或位于不可见父节点下的几何都必须忽略。
- 需要把所有可见网格烘焙到最终世界坐标后再写入 OBJ。
- 需要展开实例化紧固件，不能遗漏实例。
- 输出必须转换到 Blender 的 Z-up 坐标系，也就是在导出前应用一次绕 X 轴 `-90` 度旋转。
- `/root/output/display.obj` 必须是有效的 OBJ，包含顶点和面，并且其几何点集与上述可见装配体一致。
